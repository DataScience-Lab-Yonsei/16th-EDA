## EDA 프로젝트 요약

### 프로젝트 주제 및 목적
매일 쏟아지는 기상 관측값(기온·습도·바람·강수·미세먼지)은 단위와 방향이 달라 "오늘 밖에서 활동하기 얼마나 좋은 날인가"를 한눈에 알기 어렵다. 본 프로젝트는 전국 기상 데이터를 **인간활동 중심의 0~1 스트레스 지수**로 정규화하고, 이를 관광 데이터와 결합해 **데이터 기반 한국형 관광기후지수(KTCI)**를 산출했다. 나아가 계절별 **히든스팟**을 도출하고, 이를 실제 웹 서비스 **'날씨의 ED아이'**로 구현하는 것을 목표로 한다.

### 데이터 전처리
- **원자료 집계** : ASOS·AWS 시간별 관측을 일 단위로 집계(일평균/최고/최저, 일강수·1시간 최대강수 등). [코드](./preprocess_code/01_normalize_weather.py)
- **결측 처리** : 자료원별 결측코드 개별 처리(ASOS −9/−99, AWS −99, AirKorea −999/빈칸).
- **대기질 구조 통일** : 에어코리아 2019년 전후 컬럼 구조 차이(PM2.5 유무) 보정, PM10 fallback으로 시계열 일관화.
- **관측소→시군구 매핑** : 광역시=시도 풀, 도=시·군 기초단위로 이원화하고 META 특이표기(전남↔광주 분기, '(산지)' 접두, '수원시권선구' 결합)를 보정해 **전국 264개 시군구 100% 매핑**.
- **관광 데이터 결합** : (signguCode, baseYm) 키로 다양성·소비강도·외지인 비중 조인(중복 제거 후 결합). [코드](./preprocess_code/02_build_master.py)

### 분석 방법 및 결과
- **정규화(기상 스트레스 지수)** : 선행연구·특보 임계값을 앵커로 한 **구간선형 보간**으로 5개 영역(기온·습도·바람·강수·대기질)을 0~1로 변환(0=좋음, 1=나쁨). 기온·습도는 양방향(worse-max), 대기질은 최악물질 대표(CAI). [코드](./preprocess_code/01_normalize_weather.py)
- **검증** : 별도 보정 없이 봄 황사(PMc)·여름 오존 계절성 재현, 순열검정·부트스트랩·연도별 안정성 확인.
- **데이터 기반 KTCI** : 스트레스를 적합도(100×(1−stress))로 뒤집고, 관측률·Spearman·10분위 반응폭을 결합한 계절별 가중치로 산출. 선행연구(2014) 대비 성능 개선 확인. [코드](./KTCI_code)
- **히든스팟** : `히든점수 = 매력도(z(다양성)+z(소비)+z(외지인)) − 혼잡도(z(log 방문객))`, KTCI ≥ 계절 중앙값 필터. 계절별 1위 — 봄 군위 · 여름 가평/홍천 · 가을 공주 · 겨울 부산. [코드](./hidden_spot/03_hidden_spot.py)

### 결론
전국 3년치 실측 데이터를 선행연구 기준으로 정규화해 재현 가능한 **기상 스트레스 지수**를 만들고, 이를 **데이터 기반 KTCI**로 발전시켜 계절별 히든스팟과 실제 서비스 **'날씨의 ED아이'**까지 완성했다. 완벽한 예측이 아니라, **근거 있고 검증 가능한 '날씨–여행 쾌적도 요약 지표'**를 구축한 것이 핵심 성과다.

### 아쉬운 점 (한계)
- 정규화 임계값이 '평균 인체' 기준이라 개인차·활동유형 미반영, 선형 보간으로 급변 구간 단순화.
- KTCI 가중치가 인과가 아닌 연관성(Spearman) 기반이라 다른 요인 통제가 어려움.
- 서비스는 예보 기반이라 기상 16일·대기질 5일까지만 산출, 현재 일 단위 점수만 제공.

### 추가로 하면 좋을 분석 방법
- 비선형 함수(로지스틱)·구간 세분화로 정규화 정교화.
- **다변량 GAM·SHAP**로 다른 요인을 통제한 조건부 가중치 산출.
- 시간대별 점수, 다년 관광데이터로 확장.

## 각 팀원의 역할

| 이름 | 활동 내용 |
|---|---|
| **백가은** (팀장) | 프로젝트 총괄 및 일정·회의 관리 · **기상 RAW 데이터 정규화 설계**(선행연구·특보 임계값 기반 구간선형 보간, 5영역 기상 스트레스 지수) · **관측소–시군구 공간 매핑 및 관광 데이터 결합 파이프라인 구축**(264개 시군구 100% 매핑) · **히든스팟 도출**(매력−혼잡) · 발표자료 제작 |
| **최유성** | **데이터 기반 KTCI 설계**(`KTCI_code`) — 관측률·Spearman·10분위 반응폭을 결합한 계절별 가중치 산출, **민감도 분석 및 모델 비교·검증**, 2014 설문 기반 benchmark·Hybrid 탐색 |
| **이은민** | 웹 서비스 **'날씨의 ED아이' 개발·배포** — **'오늘의 날씨 점수'**(위치 기반 실시간 시군구 점수·5등급 분류·기상위험 자동 하향·활동 추천) 기능 설계 및 구현 |
| **신동준** | **'여행 일정 날씨 점수'(동선 점수)** 기능 설계·구현 — 예보 기반 일자별 동선 채점 및 최적 방문 일자·감점 요인 제공 |
| **김현희** | **데이터 시각화** · 기존 **TCI/KTCI 선행연구 및 한계점 분석**(서론·이론 배경) · **발표자료 총괄 편집** |
