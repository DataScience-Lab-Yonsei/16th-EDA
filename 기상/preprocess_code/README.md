# preprocess_code — 기상 정규화 · 매핑 · 마스터 결합

기상 RAW 데이터를 **인간활동 스트레스(0~1)** 로 정규화하고, 관측소를 시군구에 매핑해
관광 데이터와 결합한 **분석용 마스터**를 만드는 전처리 파이프라인입니다. (백가은)
(히든스팟 분석은 `../hidden_spot/`, 데이터 기반 KTCI 가중치는 `../KTCI_code/` 참고)

## 실행 순서

| 순서 | 파일 | 설명 |
|---|---|---|
| 1 | `01_normalize_weather.py` | ASOS·AWS·AirKorea 원본 → 시간별→일별 집계, 결측 처리, 체감온도·THI·PMc 파생, **5영역 구간선형 정규화**(0=좋음/1=나쁨) |
| 2 | `02_build_master.py` | 정규화 결과 + 관광 지표를 `(signguCode, baseYm)`로 결합해 분석용 마스터 생성 (관측소→시군구 매핑 포함) |
| - | `config.py` | 5영역 정규화 앵커(임계값)·결합 규칙 정의 |

```bash
pip install pandas numpy
python 01_normalize_weather.py --source all --output ./out
python 02_build_master.py
```

## 방법론 요약
- **정규화** : 선행연구·특보 임계값을 앵커로 한 구간선형 보간 `s(x)=sᵢ+(sᵢ₊₁−sᵢ)(x−xᵢ)/(xᵢ₊₁−xᵢ)`, [0,1] 절단.
- **결합** : 기온·습도는 worse-max(양방향), 대기질은 최악물질 대표(CAI), 결측은 재정규화(관측 2개 미만 미산출).
- **매핑** : 광역시=시도 풀 / 도=시·군 기초단위 + META 특이표기 보정 → 264개 시군구 100% 매핑.
- **검증** : 무보정 봄 황사(PMc)·여름 오존 계절성 재현, 순열검정·부트스트랩·연도 안정성.

> ⚠️ 원본 데이터(`/data/InSitu/…`)는 학교 서버에 있으며 **읽기 전용**으로만 접근합니다.
> 산출물 예시와 압축 데이터는 `../Dataset/`, 그림은 `../figures/` 를 참고하세요.
