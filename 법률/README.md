## EDA 프로젝트 요약

1. **주제 및 목적**: 공개 형사 판결문을 대상으로 두 가지를 물었다. ① 판결문의 문체는 1980–2025년 사이 어떻게 변했는가. ② 변호사 선임 유형(국선/개인/법무법인)은 양형 결과(감경·집행유예)에 영향을 주는가.

2. **데이터 전처리**: 공개 형사 판결문 코퍼스(20,984건)에서 이유부를 추출(18,778건)하고 날짜·심급·범죄군을 정리했다(문체 분석). 양형 분석은 공통 전처리 코퍼스에서 범죄군별로 필터한 뒤, 판결문 텍스트에서 형량·변호사 유형·양형사유(합의, 반성, 전과, 피해회복 등)를 정규식·수기 태깅으로 추출했다(교통 50 / 성 82 / 재산 437 / 폭력 340건).

3. **분석 방법 및 결과**:
   - **문체(00)**: Kiwi 형태소 분석으로 문장 길이·품사 구성·표현 변이를 계산하고, 심급×범죄군 표준화, 법원 고정효과·문서길이 통제 회귀(법원 군집 SE, BH 보정), 변화점 탐지와 강건성 검증을 수행했다. 문장당 어절 63.4→30.5(−52%), 명사 비율 +3.1%p, '아니하-→않-' 1991년 교차, 문장 길이 변화점 2004년(95% CI 2000–2008). 양형 문장은 짧아졌지만 완화 표현 밀도는 오히려 증가 — "완화의 언어는 압축돼 보존"됐고, 유죄 판결 이유부 말미에 집중 배치된다.
   - **양형(01–04)**: 파트별 이항 로지스틱 회귀(`outcome ~ 변호사유형 + 죄유형 + 양형사유`, 기준범주 국선). 원자료 관대처분율에서 유상 변호가 국선을 앞서는 파트는 없었고, 회귀에서도 변호사 효과는 대체로 비유의였다. 유일한 유의 결과(사기 법무법인 OR 5.08)는 결과변수가 형량·피해액의 결정론적 함수인 모형에서 나온 것으로, 보정 인공물 가능성을 함께 보고한다.

4. **결론**: ① 판결문은 45년간 문장을 절반으로 끊고 명사 중심으로 응축했으나 완화의 언어는 보존했다. ② 판결문에 기재된 양형사유는 결과의 원인이라기보다 판결문 작성 관행의 흔적에 가깝다(반성·합의 기재의 동반 출현이 2개 파트에서 독립 재현). ③ 이 표본에서 변호사 유형이 양형을 바꾼다는 증거는 없었다 — 단 "효과 없음"이 아니라 "현재 표본·측정으로는 검출 불가"가 정확한 표현이다.

5. **아쉬운 점**: 파트별로 결과변수("감경·집유")의 조작적 정의가 달라 파트 간 직접 비교가 불가했다. 공개 판결문 데이터베이스의 선택편향과 심급 혼합(3심 45~52% 파트 존재), 벌금형을 실형과 같게 0으로 코딩한 문제, 다중검정 미보정, 소표본(일부 모형 EPV<5)의 검정력 부족이 한계다. 검증 과정에서 폭력 파트의 유죄 필터가 무죄 판결문도 통과시킨 문제(표본의 29.7%)와 변호사 변수 미투입, 재산 파트의 결과변수 순환 구조를 확인해 결과 해석에 반영했다.

6. **추가 분석 방향**: 1심 판결문 한정 재수집(집단당 250–300건 확보), 벌금<집유<실형의 순서형 결과변수 통일과 공식 양형기준표 코딩, 무작위 표본 이중 수기 코딩으로 태깅 품질 검증(κ 보고), 성향점수·민감도 분석 도입.
