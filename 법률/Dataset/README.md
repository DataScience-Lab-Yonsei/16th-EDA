# Dataset 안내

## 원자료 (저장소 미포함)

용량 문제로 다음 두 파일은 저장소에 넣지 않았다. 아래 링크에서 내려받아 이 폴더에 두면 전 파이프라인을 재실행할 수 있다.

| 파일 | 크기 | 용도 | 받는 곳 |
|---|---|---|---|
| `crime.zip` | 대용량 | 문체 분석(00_문체분석) 원자료 — 공개 형사 판결문 코퍼스 | (드라이브 링크 추가 예정) |
| `EDA_data_Preprocessed.txt` | 84MB | 4개 범죄 파트 공통 전처리 코퍼스 — 교통·성 전처리 입력 | (드라이브 링크 추가 예정) |

## 포함된 파일 (파트별 태깅 산출물)

이 파일들만 있으면 각 파트의 **회귀 스크립트(02_regression)는 원자료 없이 바로 재실행**할 수 있다.

| 파일 | 생성 주체 | 내용 |
|---|---|---|
| `Traffic_offend.csv` | 01_교통범죄/01_preprocess_tag.py | 교통(음주운전·도주치상) 사건별 태깅 데이터 (50건) |
| `Sex_offend.csv` | 02_성범죄/01_preprocess_tag.py | 성범죄 사건별 태깅 데이터 (82건) |
| `Usedata.csv` | 03_재산범죄/01_preprocess_tag.R | 재산범죄 통합 분석 데이터 (437건 = 사기 248 + 횡령배임 160 + 절도 29) |
| `Fraud.csv` / `Breach.csv` / `Theft.csv` | 03_재산범죄/01_preprocess_tag.R | 사기 / 횡령배임 / 절도 하위군별 데이터 |
| `tagged_file_0.zip` | (상류 공통 태깅) | 폭력범죄 파트 입력 데이터 압축본(47MB→14.5MB). **04_폭력범죄 노트북 실행 전 이 폴더에 `tagged_file_0.csv`로 압축 해제** (cp949 인코딩) |

참고: 재산범죄 CSV 4종은 R `write.csv` 산출물이라 1열이 행 번호이고, 원본은 확장자 없이 저장된 것을 `.csv`로 통일했다.
